 UNIVERSAL ARCHITECTURE (same for Expts 1-5)
------------------------------------------------------------------------------

Transmitter chain (transmitter.vi):
  source (key bit sequence [U8]) -> MOD (data symbols [CDB]) -> add control
  -> pulse shaping

Receiver chain (receiver.vi):
  matched filter -> synch (offset [I32]) -> channel estimate -> equalize
  -> strip control -> decode -> error detect (bit-error rate [DBL])

For Expts 6 and 7 (OFDM_transmitter.vi and OFDM_receiver.vi):
  - Transmitter: adds "OFDM mod" and "Scale energy to compensate for IFFT"
    (sqrt(N)) after MOD.
  - Receiver: adds "OFDM strip control" -> "OFDM demod" -> "divide by
    sqrt(N)" before decode.


==============================================================================
 EXPT 1: DIGITAL MODULATION AND DETECTION TECHNIQUES (M-QAM)
==============================================================================

Sub-VIs used:
  - Modulate.vi : maps U8 bits to CDB constellation symbols and sets the
                  symbol energy.
  - Decode.vi   : performs Maximum Likelihood (ML) detection from CDB symbols
                  to U8 bits.

Steps to perform:
  1. Open top_tx.vi and top_rx.vi in LabVIEW.

  2. Set hardware parameters on both:
       device name        = 192.168.10.2
       IQ Sampling Rate   = 500k (S/sec)
       Carrier Frequency  = 915M (Hz)
       Active Antenna     = TX1 (on Tx) / RX1 (on Rx)
       Enabled Channel    = 0
       Gain               = 0 dB (on Tx) / 12 dB (on Rx)

  3. Set filter and frame parameters:
       TX Filter          = Root Raised Cos
       Alpha              = 0.50
       Filter Length      = 6
       Samples per Symbol = 4
       Symbol Rate        = 125k (symbols/sec)
       Reset Demodulator? = True (on Rx)

     * Written Procedure vs. Front-Panel Screenshot Note:
       - Written manual states: Packet length = 100 bits.
       - Front-panel screenshots show:
           Tx: PN Sequence Order = 9, Frame Length = 2044 samples
           Rx: Acq Duration = 5.00m (sec), Frame Size = 2500 samples,
               eye length = 2

  4. Run top_tx.vi FIRST and wait until the transmitting LED indicator turns on.
  5. Run top_rx.vi SECOND and view the "Rx Constellation", "Rx Eye Diagram",
     and "Impairment Measurements" tabs.

Parameter to change:
  - Change "QAM M-ary" across 4, 16, and 32 on both Tx and Rx.

What happens and why:
  - 4-QAM (2 bits/symbol): shows 4 well-separated corner dots in the
    constellation and a 2-level, wide-open eye diagram.
  - 16-QAM (4 bits/symbol) and 32-QAM (5 bits/symbol): display a 4x4 grid
    (16 dots) and 32 tightly packed dots, respectively.
    Because more bits are packed per symbol (M = 2^b) at the same transmit
    power, the Euclidean distance between adjacent constellation points
    shrinks, and the eye diagram splits into multiple crowded vertical
    amplitude levels, making higher-order QAM much more prone to noise.

 EXPT 2: PULSE SHAPING AND MATCHED FILTERING ANALYSIS
==============================================================================

Sub-VIs used:
  - pulse_shaping.vi     : oversamples input and applies transmit pulse-shaping
                           filter g_tx(t).
  - matched_filtering.vi : applies the matched filter g_rx(t) = g_tx(-t) to
                           maximize SNR.

Steps to perform:
  1. Open Simulator.vi (integrates top_tx.vi and top_rx.vi).

  2. Set TRANSMITTER and RECEIVER:
       TX/RX oversample factor = 4
       TX/RX sample rate       = 4M
       channel model           = AWGN
       noise power (dB)        = -Inf
       Channel response        = [1] (or [0.556+0i] in alpha=0.4 screenshot)
       Frequency offset        = 0, delay (sec) = 0
       Synchronization Method  = Timing Estimation
       Symbol Timing Recovery  = Max Energy
       Frame Detection Method  = Sliding Correlator
       Correct Frequency Offset= OFF
       Equalization Method     = Direct
       Channel estimate length = 4, Equalizer length = 4, Equalizer delay = -1

  3. Set SHARED:
       modulation type         = QPSK
       packet length (bits)    = 200
       # of iterations         = 1
       Training Sequence Type  = Length 11 Barker Sequence
       Zero Pad Length         = 8
       modulation type (filter)= PSK
       pulse shaping filter    = Root Raised
       filter length (symbols) = 8
       (Note: Written procedure also mentions Capture time = 2 msec,
        default Filter parameter = 0.5).

  4. Run the VI and open the "Received Eye Diagram" tab.

Parameter to change:
  - Vary "filter parameter" (roll-off factor alpha) through 0.2, 0.4, 0.6,
    and 0.8.

What happens and why:
  - At alpha = 0.2: the impulse response tails decay slowly, causing heavy
    waveform ringing/overshoot and a NARROW vertical eye opening.
  - As alpha increases to 0.8: the filter tails decay faster in the time
    domain, which REDUCES Inter-Symbol Interference (ISI), eliminates
    overshoot, and produces a much wider, cleaner eye diagram opening over
    the sampling period (at the cost of excess bandwidth).

==============================================================================
 EXPT 4: CHANNEL ESTIMATION AND EQUALIZATION
==============================================================================

Sub-VIs used:
  - LLSE.vi     : solves linear system Ax = b (y = Ta) via Linear Least Squares
                  to estimate channel taps h_hat and squared error ||Ax - b||^2.
  - Toeplitz.vi : generates an m-by-n Toeplitz matrix H_hat from first row and
                  column inside Equalizer.vi to compute the FIR equalizer:
                    f_hat(nd) = (H_hat* H_hat)^-1 H_hat* e(nd)

Steps to perform:
  1. Open Simulator.vi / receiver.vi and set Shared parameters:
       Packet length            = 500 bits
       Modulation               = QPSK
       Training Sequence Type   = Length 11 Barker Sequence
       Zero Pad Length          = 8
       Filter parameter (alpha) = 0.2, Filter length = 8
       Correct Frequency Offset = OFF (disabled to avoid errors)

  2. SETUP 1 (Narrowband System):
     * Written Manual Values:
         Tx sample rate = 20M, Tx oversample factor = 200,
         Rx sample rate = 2M,  Equalizer length = 1, Capture time = 3.5 msec.
     * Simulator Screenshot Values (Pages 29-30):
         Tx/Rx sample rate = 20M, Tx OSF = 200, Rx OSF = 20,
         Channel estimate length = 4, Equalizer length = 1, Equalizer delay = -1,
         Pulse shaping filter = Raised Cosine.

  3. SETUP 2 (Wideband System):
     * Written Manual Values:
         Tx sample rate = 20M, Tx oversample factor = 4,
         Rx sample rate = 10M, Rx oversample factor = 2,
         Equalizer length = 6, Channel estimation length = 6,
         Capture time = 80 usec.
     * Simulator Screenshot Values (Pages 27-28):
         Tx/Rx sample rate = 4M, Tx/Rx OSF = 4,
         Channel estimate length = 4 (or 1), Equalizer length = 6 (or 1),
         Pulse shaping filter = Root Raised.

Parameter to change:
  - Compare AWGN vs. ISI channel models (with 2-tap impulse response
    [0.8+0i, 0.547+0i] at noise power = -20 dB or -Inf).
  - In the receiver.vi block diagram, rewire the "recovered symbols" wire to
    tap the signal BEFORE vs. AFTER the "equalize" block.

What happens and why:
  - Before equalization (or with Equalizer length = 1 in an ISI channel):
    multipath delay spread causes neighboring QPSK symbols to collide,
    splitting the 4 ideal points into 16 scattered constellation clusters
    (4 clusters per quadrant) and closing the eye diagram.
  - After equalization (Equalizer length = 6): LLSE.vi uses the Length-11
    Barker sequence (N_t >= 2L+1) to estimate the channel. The Least-Squares
    FIR equalizer acts as an inverse filter, collapsing the 16 clusters back
    into 4 clean QPSK points with BER = 0.

==============================================================================
 EXPT 6: IMPLEMENTATION OF OFDM MODULATION
==============================================================================

Sub-VIs used:
  - OFDM_modulate.vi   : takes the N-point IFFT and prepends the Cyclic
                         Prefix (Lc); one OFDM symbol = (N + Lc) samples.
  - OFDM_demodulate.vi : strips Lc, takes the N-point FFT, and performs
                         1-tap Frequency Domain Equalization (FEQ): Y[k]/H[k].

Steps to perform and parameters to change:
  1. Open OFDM_simulator.vi (or top_ofdm_tx.vi and top_ofdm_rx.vi).

  2. Set base Shared & Receiver parameters:
       Packet length                     = 500 bits
       Modulation                        = QPSK
       Training Sequence Type            = IEEE 802.11a Short Training
       Zero Pad Length                   = 8
       pulse shaping filter              = Raised Cosine (alpha = 0.5, len = 8)
       FFT size (N)                      = 64
       Length of CP (Lc)                 = 8
       Null tones                        = {0, 31, 32, 33}
       Training Sequence FFT size        = 64, Training Sequence CP = 8
       Synchronization Method            = OFDM Synchronization
       Frame Detection Method            = OFDM Frame & Frequency Sync
       Channel estimate length           = 4, Equalizer length = 4, delay = -1
       Equalize Channel                  = ON (TRUE)

  3. TEST A - Narrowband vs. Wideband Channel:
       Narrowband (Written Manual):
         TX/RX sample rate = 4M, TX/RX OSF = 20, Capture time = 2.4 msec
       Wideband (Written Manual):
         TX sample rate = 20M, TX OSF = 4, RX sample rate = 10M, RX OSF = 2,
         Capture time = 100 usec
       (Note: Simulator screenshot on page 44 uses TX/RX sample rate = 20M,
        TX/RX OSF = 4, AWGN noise power = -20 dB; Hardware USRP screenshots on
        pages 44-45 use Carrier Freq = 1.93G, Gain = 30 dB, Capture = 1.25m,
        Bandwidth = 400k).

  4. TEST B - Effect of Frequency Offset & Subcarrier Count (N = 64 vs 1024):
       Set TX sample rate = 20M, TX OSF = 20 (or 4 in screenshot),
       RX sample rate = 4M (or 20M), RX OSF = 4, Capture time = 500 usec.
       Set Frequency offset (Hz) = 200 Hz (and increase in steps of 200 Hz)
       with Correct Frequency Offset = OFF.
       Compare:
         (a) FFT Size (N) = 64,   Lc = 8,  Nulls = {0, 31, 32, 33}
         (b) FFT Size (N) = 1024, Lc = 32, Nulls = {0, 511, 512, 513}

What happens and why:
  - Narrowband vs. Wideband: The Cyclic Prefix (Lc >= Lh) prevents ISI between
    OFDM symbols and converts linear convolution into circular convolution,
    allowing 1-tap FEQ division Y[k]/H[k] to produce 4 clean QPSK points.
  - Frequency Offset (200 Hz) & N = 64 vs. 1024: Frequency offset destroys
    orthogonality between subcarriers, causing Inter-Carrier Interference (ICI)
    that scatters the constellation. Because N = 1024 has 16x narrower
    subcarrier spacing than N = 64, the same 200 Hz offset causes much worse
    ICI and higher BER for N = 1024.

==============================================================================
 EXPT 7: CHANNEL CODING IN OFDM SYSTEMS
==============================================================================

Sub-VIs used:
  - repeat_encoder.vi : implements rate 1/3 repetition block code (repeats
                        each source bit 3 times: k = 1, n = 3, r = 2).
  - repeat_decoder.vi : implements majority-vote decoding on each 3-bit block.

Steps to perform:
  1. Open OFDM_simulator.vi.

  2. Set Transmitter & Receiver parameters:
       TX/RX sample rate        = 20M
       TX/RX oversample factor  = 4
       channel model            = AWGN
       noise power (dB)         = -10 (high noise to induce errors)
       channel response         = [1]
       Synchronization Method   = OFDM Synchronization
       Symbol Timing Recovery   = Max Energy
       Frame Detection Method   = OFDM Frame & Frequency Sync
       Correct Frequency Offset = OFF
       Equalize Channel         = ON

  3. Set Shared parameters:
       modulation type          = QPSK
       packet length (bits)     = 500
       # of iterations          = 10
       Training Sequence Type   = IEEE 802.11a Short Training, Zero Pad = 8
       pulse shaping filter     = Raised Cosine (alpha = 0.5, length = 8)
       FFT size (N)             = 64
       Length of CP (Lc)        = 8
       Number of OFDM Symbols   = 1
       Null Tones               = {0, 31, 32, 33}
       Training Seq FFT = 64, Training Seq CP = 8

Parameter to change:
  - Toggle the "Channel Coding Enabled" boolean switch on the SHARED panel
    from OFF to ON.

What happens and why:
  - When OFF (Uncoded): high channel noise (-10 dB) causes raw symbol errors
    to directly become bit errors (error statistic = 0.08, average BER = 0.072).
  - When ON (Coded, Rate 1/3 Repetition): each bit is sent 3 times. Even
    though the physical QPSK constellation and eye diagram remain equally
    noisy, the majority-vote decoder corrects any single-bit error per 3-bit
    codeword, cutting the average BER nearly in half (to 0.025, or 0.045 in
    single-shot view) and demonstrating CODING GAIN.

==============================================================================

Steps to perform (from Record Page 60):

     links.

 OPTICAL EXPT 3: NUMERICAL APERTURE (NA) DETERMINATION
==============================================================================

Steps to perform (from Record Page 63-65):
  1. Connect the optical fiber cable to the LED source (Optical TX2) and mount
     the output tip facing the graduated screen at distance d (cm).
  2. Measure the horizontal diameter (AB) and vertical diameter (CD) of the
     projected circular red light spot on the screen.
  3. Compute mean spot radius: x = (AB + CD) / 4.
  4. Calculate Numerical Aperture:
       NA = sin(theta_a) = x / sqrt(x^2 + d^2)
  5. Repeat for multiple screen distances d.
